# Sistema-de-Gesti-n-de-Cl-nica-Privada-Modernizaci-n-y-Rendimiento-
Sistema de gestión clínica a gran escala en Python. Implementa colas de prioridad, búsquedas avanzadas, árboles N-arios y un laboratorio de benchmarking en tiempo real (Big O) con lotes de hasta 200,000 registros para evaluar el rendimiento de estructuras de datos y algoritmos.
